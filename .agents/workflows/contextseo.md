Product context

Build an SEO SaaS platform where users enter a URL and instantly receive a clear, actionable report to improve search visibility, performance, and usability.

The analysis should cover technical SEO, on-page structure, page performance, and UX signals. Reports should prioritize issues by impact, explain why each issue matters, and provide practical fix steps.

UX and design direction

Follow a Stripe-inspired visual system: clean white surfaces, deep navy typography, purple primary actions, subtle blue-tinted shadows, and a minimal premium feel.

Keep UI language simple and outcome-focused:
- identify issues quickly
- explain impact clearly
- recommend next steps confidently

The product goal is not only to surface problems, but to guide users to fix them fast and with confidence.
